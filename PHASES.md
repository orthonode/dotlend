### PolkaVM Note
The UltraHonk verifier generated by Noir/barretenberg uses assembly blocks for BN254
pairing operations (EVM precompiles 0x06-0x08). These are standard precompile calls,
not arbitrary assembly. Deployment to Polkadot Hub TestNet is pending BN254 precompile
availability. Local tests pass using MockSolvencyVerifier (no pairing overhead).
